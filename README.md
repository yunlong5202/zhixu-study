# 知序自考

一款参照驾考刷题习惯设计的自考学习软件。支持《思想道德与法治》（15042）、《习近平新时代中国特色社会主义思想概论》（15040）与《毛泽东思想和中国特色社会主义理论体系概论》（15041），可在顶部切换课程。支持电脑、手机浏览器。

![知序自考桌面预览](screenshots/知序备考首页.jpg)

## 运行

需要 Node.js 20 或更新版本，无第三方依赖，无需安装 npm 包。

```sh
git clone https://github.com/yunlong5202/zhixu-study.git
cd zhixu-study
npm run dev
```

打开 http://127.0.0.1:5173 。Windows 下双击 `启动知序.bat` 或 `启动知序.cmd` 会启动服务并自动打开浏览器；保留启动窗口，关闭窗口即可停止服务。重复双击会打开已运行的知序页面。若端口被其他程序占用，启动窗口会显示提示；也可以设置 `$env:PORT=5174` 后再启动。服务器只提供首页、`src/` 和 `public/` 中的静态文件。

手机与电脑连接同一局域网，在手机浏览器输入电脑的局域网 IP 和端口（例如 `http://192.168.1.10:5173`）。手机和电脑记录彼此独立，可通过导出、导入 JSON 备份迁移。浏览器按访问地址隔离本地记录，建议固定使用同一地址。

## 已实现

- 学习首页：实际学习进度、今日题数、累计正确率、连续学习天数。
- 章节、顺序、随机练习：单选提交后显示正误与解析。
- 答题中查阅考点：讲解和目录顶部显示“返回当前答题”，保持本轮题序、当前题号、所选答案及提交状态；刷新后也可继续，笔试草稿自动保留。
- 直接查看答案：练习题下方可随时打开解析或笔试参考作答，关闭后继续原题；仅查看不计入练习记录，也不改变错题状态。
- 考点精讲：各科提供知识摘要、答题要点、易混提醒、大纲位置和参考来源；按章节、关键词及练习状态筛选。
- 每日任务：先复习错题及到期题，再练未做过的选择题与笔试题。答对后的间隔依次为 1、3、7、14、30 天，答错立即进入复习。
- 笔试训练：简答、论述与材料分析，输入草稿即时保存；支持纸上书写后对照参考要点自评。
- 错题本：答错或标记需要巩固自动收录，再次答对或标记掌握后移出。
- 收藏：星标、搜索题干或章节、按题型筛选。
- 模拟考试：思法采用 25 单选、5 简答、3 论述选 2；习概与毛概采用 25 单选、5 简答、1 材料题，全部作答。均有 150 分钟倒计时，保存作答，刷新或离开后仍按截止时间计时，页面重新打开时处理超时交卷。
- 分章组卷：客观题涵盖当前课程各学习单元，优先抽取未练题。选项按题号稳定打散显示，刷新后不变，存储仍兼容原始答案索引。
- 训练报告：选择题自动计分，主观题逐题自评；修改自评后重新保存可修正错题状态，不重复增加练习次数。
- 三科学习记录、笔试草稿、错题、收藏、模拟与备份分别保存；兼容已有思法记录。
- 模拟成绩摘要：保留最近 20 次；仅最近一套试卷保留详细答案和自评。
- JSON 记录备份与恢复，恢复前校验并确认覆盖。
- 备考检查：考点覆盖、选择题表现、核心笔试自评、两套不同完整模拟四项分别呈现，不将只读讲解视为掌握。
- 笔试与错题列表每页 12 题，并支持搜索和题型筛选。

## 题库说明

| 课程 | 学习单元 | 知识专题 | 原创题量 |
|---|---:|---:|---:|
| 思想道德与法治（15042） | 9 | 162 | 805 |
| 习近平新时代中国特色社会主义思想概论（15040） | 18 | 54 | 252 |
| 毛泽东思想和中国特色社会主义理论体系概论（15041） | 10 | 46 | 194 |
| 合计 | 37 | 262 | 1,251 |

![三门课程切换](screenshots/三科切换.png)

思法有 **805 道原创训练题**，其中 715 道配有专题索引，另保留旧版本 90 道情境题及其稳定 ID。按官方大纲绪论及八章共 9 个单元组织，158 个大纲知识专题和 4 个法治更新专题，映射 239 项识记、领会与应用知识要求。各专题至少有 3 道选择题和 1 道书写题，每章有综合论述。精确题量与逐章统计见 `research/bank-audit.md`，可运行 `npm run audit` 重新生成。

习概与毛概按各自全国考委大纲建立章节、考点、原创选择题、简答与材料分析。课程版本、范围与核查来源分别见 [习概说明](research/course-15040.md)、[毛概说明](research/course-15041.md)，结构统计见 `research/course-audit.json`。新增课程覆盖所有学习单元，但未宣称逐条穷尽大纲细目及特定考期的动态时政；仍需结合教材及考试通知复习。

题目、讲解和参考作答自行编写，采用分批编写与交叉审查。思法官方参考样卷的 33 个题位另作知识支持核查，见 `research/sample-validation-*.json`；新增两科的审查范围、内容修订与限制见 [习概审查](research/review-course-15040.md)、[毛概审查](research/review-course-15041.md)。知识支持核查判断软件内容是否涉及所需知识，不是使用官方答案阅卷或测得考生通过率。题目不是历年真题、官方样卷复刻或考题预测；主观题参考作答不是官方评分标准。

章节与参考组卷题量依据：[中国教育考试网《思想道德与法治》考试大纲及参考样卷](https://zikao.neea.edu.cn/res/Home/2502/9bca2915c4f3cc7ce33a14b1603dd1e7.pdf)。样卷列出题量、满分及考试时长，未列各题分值。软件采用单选 2 分、简答 6 分、论述 10 分，总分 100 的**训练配置**；实际考试以当场试卷为准。

法治部分区分 2023 年版教材与 2025 年版学习纲要表述，另标注截至 2026-10-22 核验的法律变化。法规制定、修订的考核截止口径与生效日期分别说明；正式答题应阅读题干所指版本及当次考试要求。

习概、毛概参考样卷均为 25 单选、5 简答和 1 材料题，没有材料题选做。软件采用 2/6/20 分的训练配置，总分 100；样卷未列小题分值，不能把训练分值视为已确认的正式评分标准。

四项训练门槛为：至少 90% 考点各做过两道不同选择题；至少练过 100 道不同选择题、每单元至少 10 道且最近正确比例达到 85%；至少 80% 核心考点有通过自评的笔试记录、每单元至少完成一道综合笔试题；最近两套完整分章模拟均达到 75 分、客观题至少 40/50 分、保存全部自评且两套单选重复不超过 10 题。门槛按未取整比例判断。这是复习检查清单，不能据此保证正式考试及格；仍需结合适用教材学习并如实自评。

## 数据与边界

没有账号、后台或云端同步；学习记录只写入当前浏览器的 localStorage，不会上传。清理浏览器数据会删除记录，请按课程分别导出备份。常规学习备份含作答记录、笔试草稿、收藏、每日统计、成绩摘要与最近练习游标；进行中的模拟考试和最近详细试卷保存在本机单独的记录中，暂不随备份迁移。导入备份只覆盖当前课程学习记录并清除该科本机详细试卷（导入前会提示确认），跨科备份会拒绝导入。程序使用本地时区统计日期。

旧版已完成自评的详细试卷缺少逐题计数凭据，升级后仍能查看和修订分数，但不会再次计入累计练习或改动旧错题状态；报告中会显示说明。新版试卷支持反复修正自评，且不会重复增加练习次数。

页面为纯静态 ES Modules，不依赖外部字体或网络接口。首次加载需要连接本地服务器；当前没有离线缓存。

## 开发和部署

```powershell
npm run check
npm test
npm run audit
npm run build
```

构建结果在 `dist/`，可部署到 Nginx 等静态服务器的站点根目录。路由采用 hash，无须配置路由重写。当前开发服务器用于本地体验，正式部署应使用 HTTPS 静态托管。

阿里云 ECS 等 Linux 服务器的配置步骤及 Nginx 模板见 [部署说明](deploy/README.md)。当前版本的刷题、评分与存储均在浏览器内完成，2 vCPU / 2GB 内存可作为静态站点的起步配置；实际访问容量还取决于公网带宽和流量。上传构建后的 `dist/` 即可，无需在服务器常驻 Node.js 或数据库，也不会自动获得账号与跨设备同步功能。

- `src/app.js`：页面、交互及模拟考试流程。
- `src/styles.css`：响应式布局及视觉样式。
- `src/data/curriculum.js`：课程、章节、题目及依据说明。
- `src/data/banks/`：按学科内容分批组织的专题与原创题。
- `src/data/sources.js`：来源清单，由 `node scripts/sync-sources.mjs` 生成。
- `src/lib/study.js`：存储校验、学习记录、随机组卷及训练评分。
- `src/lib/preparation.js`：考点进度、每日任务、间隔复习、备考检查与分章组卷。
- `src/views/preparation.js`、`src/preparation.css`：知识与备考页面。
- `research/coverage-*.json`：逐条大纲映射；`review-*.md`：内容与软件交叉审查。
- `tests/`：实际题库审计、组卷、记录兼容、自评、选项映射及训练门槛测试。

题目采用稳定 ID。课程注册位于 `src/data/catalog.js`，15040、15041 的数据模块位于 `src/data/courses/`，15042 保留原 `curriculum.js` 与专题分卷。新增科目时需要同时增加课程、章节和对应题目，并在练习筛选与存储中按 `courseId` 隔离。
